# Security policy

## Reporting a vulnerability

Please **don't open a public issue or pull request** for a security problem.

Report it through <https://rootherald.io/contact> — choose **Security
disclosure**. That form is the reporting channel; there's no separate address to
find.

It helps if you can include:

- which component and version — SDK, API, or a specific repo
- steps to reproduce, and what an attacker gains
- any proof-of-concept you're willing to share
- how you'd like to be credited, if at all

We'll confirm we've received it and keep you in the loop while we investigate.
Please give us a chance to ship a fix before publishing.

## Disclosure

We work to a coordinated disclosure model: we fix, release, and then publish an
advisory crediting the reporter unless they'd rather stay anonymous.

There's no bounty programme.
